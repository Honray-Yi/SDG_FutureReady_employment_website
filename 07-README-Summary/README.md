# FutureReady Project Summary

**Project:** FutureReady: AI-Ready Career Pathways  
**Challenge:** Aiversecity Future-Ready Workforce Domain  
**Live prototype:** https://future-ready-demo.onrender.com/  
**GitHub:** https://github.com/Honray-Yi/SDG_FutureReady_employment_website  
**Primary SDG:** SDG 4, with supporting SDG 8 and SDG 10 alignments.

FutureReady helps students, graduates, career changers, working adults, and career advisers explore how skills relate to AI-era occupations. It connects skills intake, dated AI/workforce trend evidence, ranked role matches, learning pathways, role/skill SDG mappings, and moderate/fast uncertainty scenarios.

The complete repository includes a React/TypeScript frontend, FastAPI backend, 65-role catalogue, source-linked data snapshots, local multilingual E5 semantic matching, setup and verification scripts, a Word PRD, and a ten-slide pitch deck. The public free deployment demonstrates synthetic profiles and matching. Model-backed résumé analysis requires a local deployment with downloaded model assets and at least 4 GB of memory.

Similarity values are not hiring probabilities or proof of competency. The mappings describe potential SDG contributions and are not UN endorsements or measured impact. The live demo is for synthetic data; do not upload real résumés.
