产品需求文档｜核心流程版

本文按产品功能的目标完成态编写，用于项目说明与验收定义；不作为未经验证功能的测试通过证明。

## 1. Problem — 问题定义

学生、初入职场者及转型者通常难以把自己的经历与 AI 相关职业建立清晰联系。职业描述涉及大量技术术语，用户还需要自行寻找可信、可访问且与目标职业相关的学习资源，过程分散、耗时，容易受到无依据的匹配分数或课程宣传误导。

FutureReady 将简历文本、职业描述和有来源记录的课程集中在同一条流程中：上传简历，检查提取内容，获得职业语义匹配结果，再查看对应的基础学习资源，减少初步职业探索和学习资料筛选的操作成本。

**核心用户需求：**“我希望上传一份简历后，能够看见系统读到了什么、与哪些职业更接近，以及可以从哪些课程开始学习。”

**成功标准：**完整走通“简历上传 → 文本提取与确认 → 计算 → 职业及匹配百分比 → 对应课程”，各步骤使用同一份输入和选中的职业，不跳转到无关演示结果。

## 2. SDG Alignment — 可持续发展目标对齐

### 主要目标：SDG 4 — Quality Education（优质教育）

对应目标 4.4：增加具备就业、体面工作及创业相关技能的青年和成年人数量。产品通过展示公开学习资源、课程提供方、推荐理由及访问条件，为用户制定基础学习方向提供支持。

### 次要目标：SDG 8 — Decent Work and Economic Growth（体面工作和经济增长）

对应目标 8.5：促进充分和生产性就业及体面工作。产品帮助用户理解经历与职业描述的联系，支持求职准备和职业转型；不提供职位录用保证，也不替代招聘评估。

### 支持方向：SDG 10 — Reduced Inequalities（减少不平等）

对应目标 10.2：促进社会、经济和政治包容。产品使用可公开访问的基础学习资源和明确的费用说明，降低职业探索的信息门槛。可访问性和低成本资源属于设计方向，不等于已证明消除了机会差异或模型偏差。

**影响评估建议：**记录流程完成率、课程链接访问率和用户对解释清晰度的反馈；不得以匹配分数上涨代替就业效果证明。需要收集统计数据时另行说明并获得必要授权。

SDG 官方参考：https://sdgs.un.org/goals/goal4 、https://sdgs.un.org/goals/goal8 、https://sdgs.un.org/goals/goal10 。

## 3. Target Users — 目标用户

- **学生及应届毕业生：**通过课程、项目和实习经历探索初步职业方向。
- **初入职场者及转型者：**将现有经历与 AI、数据及相关职业描述进行比较，寻找学习起点。
- **职业辅导与培训支持人员：**在取得资料处理授权后，辅助解释匹配结果及课程来源；不能据此对人员作录用或能力判定。

共同使用条件：能提供可复制文本的 PDF、DOCX，或自行粘贴经历；上传前确认有权处理资料，并了解其会在应用后端临时处理。

## 4. Scope — 范围

### MVP 范围内

1. 接受文字版 PDF、DOCX 简历及粘贴文本；文件不超过 8 MB，PDF 不超过 20 页。提取文本不超过 100,000 字符，模型输入不超过 12,000 token；超限明确提示。
2. 提取简历正文并允许用户检查、修正。这里的“信息提取”是文档正文提取，不宣称已完成姓名、学历、技能等字段的结构化识别。
3. 使用后端本地开源多语言模型，将简历与 65 个职业描述进行比较并排序；中英文使用同一处理流程。
4. 显示职业名称、说明、排名和语义匹配百分比；保留原始余弦值及解释。
5. 根据当前所选职业的明确主题展示有来源记录的课程、推荐依据、提供方、官网链接、核验日期和费用说明。
6. 提供处理授权、加载进度、错误提示、重试和清除操作。修改输入或重新上传时清除旧结果，避免新旧简历和课程错配。

### MVP 范围外

- 扫描图片简历的 OCR、手写内容识别及任意格式文档支持。
- 真实账号系统、简历历史存储、跨设备同步和后台用户管理。
- 对个人技能掌握度、缺失技能、就业市场需求或录用概率作自动判定。
- 实时招聘职位、自动投递、课程报名支付或学习完成认证。
- 为每个细分职业提供完整、已审核的全部专业课程和先修链。
- 在本次核心流程中调用 OpenAI 或其他外部分析 API。

## 5. Key Features — 核心功能

### F1. 上传与授权

用户确认资料处理授权后，可上传支持的文件。系统检查格式、体积及解析限制；空文件、损坏文件、扫描件或超限文件给出可理解的提示，不返回占位分析结果。建议用户预先移除联系方式等无关隐私。

**验收：**授权前上传/分析不可用；有效 PDF、DOCX 可以提取；未授权、损坏、无文字和超限输入被明确拒绝。

### F2. 提取与确认

系统展示提取文本及文档信息，用户可在分析前查看和修改。文档页数仅作为解析信息，DOCX 不承诺与 Word 排版页数完全一致。系统不将未提取到的内容补成虚构经历。

**验收：**提取内容与上传文档一致；用户修改的文本成为下一次分析的实际输入。

### F3. 本地语义计算

使用 multilingual-e5-small 的原生 384 维表示；长文本分块、加权聚合并归一化，计算与职业描述的余弦相似度。职业索引固定版本并校验一致性。模型不可用时明确报错，不使用随机分数、旧手工特征分数或外部 API 作为静默替代。

**验收：**同配置、同输入可重复；不同经历能产生不同结果；65 个职业完整排序，职业 ID 与描述一致。

### F4. 职业及百分比

百分比公式为：语义匹配度 = max(0, cosine similarity) × 100，保留一位小数；排序仍使用原始余弦值。用户可查看职业描述并选择其他职业。

该百分比不是录用概率、技能掌握率或模型准确率，各职业分数不需要合计为 100%。E5 的数值可能整体偏高，应结合排名、差距和原始文本解释。

**验收：**列表、详情和导出结果的职业、排名、原始值及百分比一致；不存在为制造差距而任意重标分数的行为。

### F5. 对应课程

当前所选职业通过其描述中的明确主题关联到现有、具备来源记录的课程。每个职业可展示最多 3 门相关基础课及 1 门通用责任 AI 基础课。课程卡片展示标题、提供方、主题、推荐理由、职业依据、官网、核验日期、访问及可能的额外费用。

这属于面向职业的基础学习建议，不表示已从简历推断个人技能缺口。没有专项覆盖时说明限制，不把通用基础课说成完整的专科训练；当前费用、先修条件和可用性以提供方官网为准。

**验收：**切换职业后课程与职业同步切换；课程可打开对应提供方页面；课程接口失败可以独立重试，不伪造或替换成无关演示数据。

### F6. 状态、隐私与可靠性

原文件、提取文本和简历向量不持久保存；解析、分词和推理在本应用后端临时完成，不传给外部分析服务。模型文件仅在安装或构建时下载。前端输入及结果仅保留于当前页面内存，用户主动下载结果除外。

系统限制上传、解析时间、输入长度、并发和计算次数，明确显示忙碌或限流状态。个人资料处理授权不等于已经满足所有生产隐私法规；正式公开服务仍需单独评估认证、配额隔离和隐私合规。

**验收：**再次上传和清除操作不会保留旧排名或课程；错误消息不回显简历原文；关键路径通过自动化及浏览器端到端验证。
