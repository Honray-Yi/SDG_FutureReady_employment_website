# Submission package

This folder contains the completed project submission and technical tools declaration. Replace only the clearly marked team identity fields before submission.

- `completed-submission-template.docx` and `.md`: populated project narrative and requirement mapping. Team name, members, and contact still need to be entered.
- `tech-tools-declaration.docx` and `.md`: AI assistance, model, development stack, hosting, data, and privacy disclosure. Confirm RunPod status and sign it.
- `evidence/replit/`: upload Replit utilization proof.
- `evidence/runpod/`: upload proof only if RunPod was used; otherwise it is not applicable.
- `demo/youtube-demo-link.txt`: paste the YouTube URL after uploading the product demo.

The PRD and pitch deck are in `docs/deliverables/`. The Live Prototype and repository links are in the root README.
